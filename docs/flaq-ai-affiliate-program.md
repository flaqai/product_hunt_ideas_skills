# Flaq AI 联盟推广指南

[Flaq AI Affiliate Program](https://flaq.ai/affiliate-program/) 面向开发者、创作者、教育者、AI Agent 构建者、模型评测者和创意团队。参与者可以创建个人推荐链接，向真正需要图像、视频、音频、语言模型和多模态 API 的用户介绍 Flaq AI，并从符合条件的订单中获得佣金。

> [!IMPORTANT]
> 联盟规则会变化。以下内容于 2026-08-13 根据官方公开页面核对。推广、预计收入或安排投放前，必须重新阅读当前联盟协议、归因状态、支付要求与有效政策。

## 当前公开佣金结构

| 符合条件的推荐行为 | 当前公开佣金 |
|---|---:|
| 被推荐用户的首笔有效付费订单 | **20%** |
| 注册后归因窗口内的后续有效付费订单 | **10%** |
| 归因窗口 | **注册后 60 天** |

最终可支付佣金会受到有效归因、退款、拒付、风险取消、政策滥用、账户审核和获批合作条款的影响。

## 适合的推广内容

- Product Hunt 发布素材制作与发布复盘；
- AI 图像、视频、音频或 LLM API 集成教程；
- Agent 与自动化工作流；
- 有证据的模型比较和真实成本说明；
- 产品演示、广告素材、缩略图和社媒内容工作流；
- 面向开发者、创作者和产品团队的课程或社区分享。

## 如何加入

1. 打开[官方联盟计划页面](https://flaq.ai/affiliate-program/)并登录 Flaq AI 账号。
2. 完成联盟资料并接受当前协议。
3. 在联盟工作区创建带个人 `via` 标识的推荐链接。
4. 在相关教程、评测、社区、网站或内容中分享，并明确披露推荐关系。
5. 在联盟工作区查看归因活动、链接状态和支付设置。

## 负责任的联盟披露

推荐关系必须清楚、靠近推广链接，并使用读者容易理解的语言。不要隐藏推荐参数，不要承诺固定收益、保证订单、保证模型效果或长期不变的佣金。

可使用以下简短披露：

> 联盟披露：如果你通过本文中的 Flaq AI 推荐链接注册或完成符合条件的购买，我可能获得佣金，这不会增加你的购买价格。
