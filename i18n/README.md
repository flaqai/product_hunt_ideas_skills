## 本地化规则

1. 保留 Product Hunt、Codex、Flaq AI 和字段名等专有名词。
2. 保持日期、产品数量、佣金、社区规模、访问限制和风险说明一致。
3. 联盟条款必须链接官方页面并注明可能变化。
4. 微信群必须强调真实反馈和合规互助，不宣传机器人、买票或操纵排名。
5. 新语言由熟悉该语言的人复核后再加入支持列表。
