# Product Hunt Daily Skill

[简体中文](../README.md) · [English](../README.en.md) · **Русский** · [12 языков](README.md)

Skill для Codex, который через встроенный браузер и без токена Product Hunt API собирает списки All и Featured за выбранную дату, сведения о продуктах, Launch Team/Hunter и публичные профессиональные контакты с официальных сайтов. Результаты экспортируются в JSON, CSV и Markdown вместе с аудитом контактов и реестром источников; реальные запуски индексируются по датам.

Product Hunt полезен для поиска новых продуктов, анализа конкурентов, ранней обратной связи, поиска основателей и партнёров, подготовки контента и наблюдения за трендами. Место в рейтинге само по себе не доказывает удержание, выручку, качество или долгосрочный успех.

```text
Используй product-hunt-daily и встроенный браузер, чтобы собрать полные списки All и Featured за сегодня, детали продуктов, команды и публичные профессиональные контакты, затем экспортировать JSON, CSV и Markdown.
```

«Сегодня» определяется в часовом поясе `America/Los_Angeles`. См. [основной README на китайском](../README.md) или [полную английскую версию](../README.en.md).
