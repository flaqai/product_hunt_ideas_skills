# Product Hunt Daily Skill

[简体中文](../README.md) · [English](../README.en.md) · **한국어** · [12개 언어](README.md)

Product Hunt API 토큰 없이 Codex 내장 브라우저로 특정 날짜의 All/Featured 목록, 제품 상세 정보, Launch Team/Hunter, 공식 사이트에 공개된 업무용 연락 채널을 수집하는 Skill입니다. JSON, CSV, Markdown, 연락처 감사 보고서와 출처 목록을 만들고 실제 실행 결과를 날짜별로 보관합니다.

## Product Hunt의 가치

신제품 발견, 경쟁 제품 조사, 초기 출시 피드백, 창업자와 생태계 탐색, 파트너십 조사, 콘텐츠 기획, 장기 트렌드 관찰에 활용할 수 있습니다. 순위만으로 유지율, 매출, 품질 또는 지속적인 성공을 판단해서는 안 됩니다.

```text
product-hunt-daily Skill과 내장 브라우저를 사용해 오늘의 전체 All/Featured 목록, 제품 상세, 팀, 공개 업무 연락 채널을 수집하고 JSON, CSV, Markdown으로 내보내 주세요.
```

“오늘”은 `America/Los_Angeles` 기준입니다. 자세한 내용은 [기본 중국어 README](../README.md) 또는 [영문 전체판](../README.en.md)을 확인하세요.
